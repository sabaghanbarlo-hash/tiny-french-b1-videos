VOCABULARY
s'entendre bien avec (sahn-TAHN-druh byan ah-VEHK) - to get along with
se disputer (suh dees-pew-TAY) - to argue
se réconcilier (suh ray-kohn-see-LYAY) - to make up
s'énerver (say-nehr-VAY) - to get annoyed
se pardonner (suh par-doh-NAY) - to forgive each other
préoccupé / préoccupée (pray-oh-kew-PAY) - worried
les affaires (lay zah-FEHR) - belongings, things
l'un contre l'autre (luhn KOHN-truh LOH-truh) - against each other
finir par (fee-NEER pahr) - to end up (doing)

GRAMMAR
Reciprocal verbs - A reciprocal verb describes an action two or more people do to each other: nous nous parlons, ils se disputent, vous vous voyez. They use the same reflexive pronouns: nous nous, vous vous, se. In the passé composé they take être: nous nous sommes disputés. The participle agrees with the pronoun when it is the direct object: elles se sont vues; no agreement when it is indirect: elles se sont parlé, ils se sont écrit.
Finir par, l'un l'autre - Finir par plus infinitive means to end up doing something: on finit toujours par se pardonner. L'un l'autre / les uns les autres add emphasis to reciprocity: ils s'aident les uns les autres, elles se parlent l'une à l'autre. With a preposition, put it between: l'un contre l'autre, l'un avec l'autre.
