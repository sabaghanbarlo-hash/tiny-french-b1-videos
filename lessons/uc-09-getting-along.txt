title: Getting Along
episode: UC9

[story]
Marinette: Tu as l'air préoccupé. Qu'est-ce qui se passe ? | You look worried. What's going on?
Adrien: Chloé et moi, nous nous sommes disputés hier. Nous ne nous parlons plus depuis ce matin. | Chloé and I had an argument yesterday. We haven't spoken to each other since this morning.
Marinette: Pourtant, vous vous entendez bien d'habitude, non ? | But you normally get along well, don't you?
Adrien: Oui, mais elle avait pris mes affaires sans me prévenir. Nous nous sommes énervés l'un contre l'autre. | Yes, but she had taken my things without telling me. We got angry at each other.
Marinette: Vous devriez vous réconcilier avant ce soir. Vous vous écrivez parfois ? | You should make up before tonight. Do you ever write to each other?
Adrien: Tu as raison. Je vais lui écrire. On finit toujours par se pardonner. | You're right. I'll write to her. We always end up forgiving each other.

[grammar]
grammar: Reciprocal verbs | A reciprocal verb describes an action two or more people do to each other: nous nous parlons, ils se disputent, vous vous voyez. They use the same reflexive pronouns: nous nous, vous vous, se. In the passé composé they take être: nous nous sommes disputés. The participle agrees with the pronoun when it is the direct object: elles se sont vues; no agreement when it is indirect: elles se sont parlé, ils se sont écrit.
example: Nous nous sommes disputés. | We had an argument.
example: Elles se sont parlé hier. | They spoke to each other yesterday.
grammar: Finir par, l'un l'autre | Finir par plus infinitive means to end up doing something: on finit toujours par se pardonner. L'un l'autre / les uns les autres add emphasis to reciprocity: ils s'aident les uns les autres, elles se parlent l'une à l'autre. With a preposition, put it between: l'un contre l'autre, l'un avec l'autre.
example: On finit par se pardonner. | We end up forgiving each other.
example: Ils s'aident les uns les autres. | They help each other.
